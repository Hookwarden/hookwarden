# hookwardne

This package is a typo-defense shim for [hookwarden](https://www.npmjs.com/package/hookwarden).

If you meant to install the canonical package, run:

```
npx hookwarden@latest scan
```

See https://hookwarden.dev for documentation.

This package re-exports `hookwarden` and prints a notice when invoked. License: Apache 2.0.
