# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful and constructive. Harassment, personal attacks, and demeaning or discriminatory behavior are not tolerated, in any project space (issues, PRs, discussions).

**Reporting:** report unacceptable behavior privately via GitHub to the repository owner. Reports are handled confidentially. Maintainers may remove, edit, or reject contributions and contributors that violate this code.

The full text and enforcement guidelines are at the link above.
